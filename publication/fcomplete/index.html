Modeling Longitudinal Data Using Matrix Completion

Lukas Kidzinski, Trevor Hastie

Journal of Computational and Graphical Statistics 33(2), 551–566
Preprint Paper Code Project

We use matrix completion to estimate smooth individual trajectories from sparse and irregular longitudinal measurements. The framework also supports multivariate measurements and regression.

Published in Journal of Computational and Graphical Statistics, 33(2), 551–566 (2024), following online publication on November 15, 2023. Read the published paper.

Earlier versions circulated as Longitudinal data analysis using matrix completion. The preprint and fcomplete package remain available.
